 # aggregator-ts

 A TypeScript project for collecting and aggregating data from multiple sources.

 ## Getting started

 ### Prerequisites

 - Node.js 18 or later
 - npm, pnpm, or yarn

 ### Installation

 ```bash
 git clone <repository-url>
 cd aggregator-ts
 npm install
 ```

 ### Development

 ```bash
 npm run dev
 ```

 ## Available scripts

 ```bash
 npm run build    # Build the project
 npm test         # Run tests
 npm run lint     # Check code quality
 ```

 ## Configuration

 Copy the example environment file, if available, and update it with your local settings:

 ```bash
 cp .env.example .env
 ```

 Do not commit secrets or local environment files.

 ## Usage

 Import the aggregator from your TypeScript application and provide the sources or inputs to combine. Refer to the source code and tests for the supported options.
